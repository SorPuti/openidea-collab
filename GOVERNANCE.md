# Governance

SorPuti maintains this repository and its publisher identity. The project remains open source under MIT; dependency licenses and notices apply separately. Contributions are reviewed through pull requests with verification and disclosed limitations.

OpenIDEA maintainers own the IDE API and release decisions. The community registry maintainers independently decide marketplace listing. The relay operator is responsible for infrastructure, TLS, access/admission policy, privacy, costs, availability and updates. No hosted availability is guaranteed by publishing this source.

Ownership declarations do not authorize deployment, DNS changes, paid infrastructure, release signing or changes to another repository's permissions.
