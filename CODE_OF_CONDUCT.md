# Code of conduct

Contributors and users are expected to treat each other respectfully, discuss technical disagreements with evidence, and protect private project content and credentials. Harassment, threats, discrimination and publishing another person's private information are not acceptable.

Maintainers may remove abusive content or restrict participation to protect the community. Report security-sensitive incidents through the private channel described in SECURITY.md. For other conduct concerns, contact the repository maintainer through a private GitHub channel when available; do not post private information in a public issue.
