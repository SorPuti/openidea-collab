# Security policy

No version currently has a supported security guarantee for collaboration on valuable or sensitive projects. The marketplace review remains open; known limitations are tracked in [docs/security.md](docs/security.md).

Report a new vulnerability through the repository's GitHub **Security → Report a vulnerability** option when available. If private reporting is unavailable, open an issue requesting a private reporting channel without posting exploit details, credentials or private file contents. This project does not yet promise a response time.

Use synthetic data for reproductions. Include the affected commit/version, component, impact and minimal reproduction. Do not publish signing keys or access tokens.
